# Portfólio Profissional - Luiz Maranhão

Este é o meu portfólio pessoal, desenvolvido com foco em performance, design moderno e responsividade. O projeto centraliza meus principais trabalhos como Desenvolvedor Full Stack, destacando habilidades em Front-end e Back-end.

![Preview do Portfólio](/public/projeto-viagens.png) 

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as ferramentas mais modernas do ecossistema Web:

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Linguagem:** TypeScript
- **Estilização:** SASS (SCSS) com arquitetura modular
- **Deploy:** Vercel
- **Testes:** Vitest (Testes Unitários)

## 🛠️ Funcionalidades

- **Design Responsivo:** Adaptado para dispositivos mobile, tablets e desktop.
- **Seção de Skills:** Visualização do nível de proficiência técnica por tecnologia.
- **Grid de Projetos:** Organização dinâmica dos repositórios e deploys ativos.
- **Otimização SEO:** Estrutura focada em indexação e acessibilidade.

## 📁 Estrutura do Projeto

- `/src/app`: Rotas e componentes principais.
- `/src/styles`: Arquivos SCSS globais e variáveis de estilo.
- `/public`: Ativos estáticos como imagens dos projetos e perfil.

## 🔧 Como rodar o projeto localmente

```bash
# Clone o repositório
git clone [https://github.com/LuizMaranhao/Portf-lio---Luiz-Maranh-o.git](https://github.com/LuizMaranhao/Portf-lio---Luiz-Maranh-o.git)

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
